# NER-SAFE: AI-powered Landslide Early Warning System

A comprehensive disaster-management platform for predicting, monitoring, and responding to landslide risks in the North Eastern Region. It combines environmental data (rainfall, soil moisture, terrain) with an AI risk engine to provide proactive early warnings, GIS-based situational awareness, and emergency response coordination.

## Features
- **Responsive Dashboard:** View interactive simulated GIS maps and risk summaries across desktop, tablet, and mobile.
- **Simulated GIS Map:** Visualize risk zones with color-coded markers (Green, Yellow, Orange, Red) and interactive detail panels.
- **Risk & Priority Summary:** Monitor live metrics, including high-risk zones, active alerts, blocked roads, and unverified reports.
- **Incident Prioritization:** Sort and manage emergency responses based on calculated risk and impact priority.
- **Cross-Platform:** Built with Flutter, fully supporting Web, Mobile, and Desktop environments.

## Tech Stack
- Framework: Flutter
- UI/UX: Material 3, Responsive LayoutBuilder
- State Management: Provider (conceptualized for larger scale)
- Maps: Custom interactive canvas-based simulation (hackathon/demo mode)

## How to Run
1. Ensure Flutter is installed.
2. Run `flutter pub get` to fetch dependencies.
3. Use `flutter run -d chrome` (for web) or `flutter run` for your target device.
